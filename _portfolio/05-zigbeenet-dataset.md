ZigBeeNet is a decrypted ZigBee IoT network traffic dataset collected from 15 devices in a smart-home environment over 20 days. It supports reproducible research on IoT security, device fingerprinting and traffic modelling.

The dataset is described in *ZigBeeNet: Decrypted Zigbee IoT Network Traffic Dataset in Smart Home Environment*, published in **Applied Sciences** (2024).

- Dataset: [zenodo.org/records/13957307](https://zenodo.org/records/13957307)
- Paper: [doi.org/10.3390/app142310844](https://doi.org/10.3390/app142310844)
