Synthetic network traffic is essential for testing intrusion-detection systems and network simulators without exposing real user data. This project explores how large language models, including low-latency and reasoning models, can generate realistic ZigBee IoT traffic.

The accompanying paper, *When LLMs speak ZigBee: exploring low-latency and reasoning models for network traffic generation*, was published in **Scientific Reports** (2026).
