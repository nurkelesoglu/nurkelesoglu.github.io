LoRa networks offer long range and low power, but their localization accuracy is limited. This project applies machine learning to signal measurements to improve outdoor positioning accuracy.

The results were published as *Enhancing LoRa-Based Outdoor Localization Accuracy Using Machine Learning* in **IEEE Access** (2025).
